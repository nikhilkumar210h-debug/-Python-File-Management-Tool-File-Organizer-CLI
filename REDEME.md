## 📁 Smart File Renamer & Organizer (Python)

- A clean and efficient Python-based utility developed by Nikhil Kumar to automatically rename cluttered files in a directory based on their file types. This script organizes files using structured naming conventions, making file management simple and efficient.

## 🚀 Features
- 🔤 Automatic file renaming based on extensions
- 📂 Supports multiple file types:
- Images (.png, .jpg)
- Documents (.pdf, .txt, .docx)
- Media (.mp4, .mp3)
- 🔢 Sequential numbering for each file type
- 🧹 Sorted processing for consistent output 
- 💡 Beginner-friendly and easily extendable
## 🛠️ How It Works

- The script:

- Takes a folder path as input
- Reads all files in the directory
- Identifies file types using extensions
- Renames files using predefined labels and counters

## Example:

- imageA.png → png 1.png
- video.mp4 → video 1.mp4
- file.pdf → pdf 1.pdf

## ▶️ Usage
- git clone https://github.com/your-username/file-renamer.git
- cd file-renamer
- python main.py
## 📌 Requirements
- Python 3.x
- No external libraries required
### ⚠️ Notes
- Make sure the folder path is correct
- Avoid running on important folders without backup
- Existing files with the same name may be overwritten
